# Cluster P3.5 — Remote MCP connection (prototype)

## What works in code
- `agent_terminal/remote-mcp.cjs` implements MCP JSON-RPC over HTTP POST `/mcp` with `initialize`, `ping`, `tools/list`, `tools/call`.
- Calls authenticated with a separate bearer token stored at `%LOCALAPPDATA%\ClusterTerminalAgent\remote-mcp-token`.
- The HTTP bridge listens on `127.0.0.1:43880` and forwards to the paired local Agent at `127.0.0.1:43879`.
- The browser's AI Agent tab must remain connected to supply live editor data.
- Only already-open documents are listed; `read_file` currently requires a saved document of at most 16 KiB. No file edits or terminal execution through MCP yet.

## Windows setup
1. Re-run `Install-Cluster-Terminal.cmd` to install the latest scripts, and confirm the AI Agent tab says connected.
2. Open `%LOCALAPPDATA%\ClusterTerminalAgent\app\start-remote-mcp.cmd` to start the HTTP MCP bridge.
3. Read the remote token locally: `Get-Content "$env:LOCALAPPDATA\ClusterTerminalAgent\remote-mcp-token"`. Do **not** share this token in chat or screenshots.
4. For local verification, in PowerShell:
```powershell
$token = Get-Content "$env:LOCALAPPDATA\ClusterTerminalAgent\remote-mcp-token"
$headers = @{ Authorization = "Bearer $token" }
$body = @{jsonrpc='2.0';id=1;method='tools/list';params=@{}} | ConvertTo-Json -Depth 5
Invoke-RestMethod -Uri http://127.0.0.1:43880/mcp -Method Post -Headers $headers -ContentType 'application/json' -Body $body
```
5. To make this accessible remotely, deploy a **trusted HTTPS reverse tunnel** pointing to `http://127.0.0.1:43880` and enforce authentication at the edge. Do not expose port 43879 or the pairing token. A permanent domain/tunnel configuration is required for stable ChatGPT connector registration.
6. In an MCP-capable client that supports custom bearer headers, register `https://YOUR-HTTPS-MCP-DOMAIN/mcp` with the remote token as Authorization Bearer. Test `cluster.get_status`, then `cluster.list_files`.

## ChatGPT compatibility warning
This prototype is **not** yet a turnkey ChatGPT web connector. ChatGPT's connector creation may require OAuth and supported MCP transport/session behavior. This service currently implements stateless JSON responses and static bearer authentication; it has not been verified against ChatGPT's connector registration. A real HTTPS domain, tunnel, and possibly an OAuth authorization server are outstanding. Do not paste the remote bearer token into ChatGPT conversation messages.
